🎮 Rock, Paper, Scissors – Python Game
A simple interactive Python game where the user plays Rock, Paper, Scissors against the computer.
The program includes ASCII-style icons, rule explanations, input validation, and random computer choices.
---------------------------------------------
🚀 Features
ASCII icons for Rock, Paper, and Scissors

Random computer selection

Input validation for incorrect choices

Optional help menu explaining the rules

Clear win/lose/draw messages

Beginner‑friendly Python code
----------------------------------------------
🧠 How It Works
The script uses:

random.choice() to generate the computer’s move

input() to get the user’s choice

Conditional statements to determine the winner

Simple ASCII art to make the game more fun
-----------------------------------------------
▶️ How to Run
Make sure Python is installed

Download the script

Run it using: python rock_paper_scissors.py
